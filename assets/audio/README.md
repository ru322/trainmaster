# assets/audio

`tm-audiogen` の入力(正は `docs/detail/14-platform-audio.md` §5.2〜§5.4)。

- `<名前>.ron` が 1 つの音。名前は `^(se|bgm|jingle)_[a-z0-9_]+$`。`_` で始まるファイルとディレクトリ(`_lib/`)は共有の定義で、音ではない。
- 数値はすべて整数。生成は `mise run assets:gen`、試聴は `cargo run -p tm-audiogen -- render assets/audio/<名前>.ron -o /tmp/x.wav [--loops N]`。
- 本番の音(IMP-302、14 §6)。`_lib/instruments.ron` が共有の音色、`_lib/game_theme.ron` が `bgm_game_1〜3` で共有する冒頭 2 小節の動機(音色 `mel` は曲ごとに定義)と `_2`・`_3` のドラム。動機の後の主旋律は曲ごと(IMP-812、14 §6.5)。
- 波形の検査(切り詰め、音量のそろい、長さ、ループの継ぎ目)は `cargo test -p tm-audiogen --test assets_audio`。

## 譜面の 1 行

空白で区切った 3〜5 個の項目: `音 音色 音量 [効果1] [効果2]`。

| 項目 | 書き方 | 意味 |
|---|---|---|
| 音 | `C-4`、`C#4`、… `B-8` | 新しい音(位相とビブラートを 0 から)。A-4 = 440Hz |
| | `N-0`〜`N-F` | ノイズの音(速さの番号。`N-0` が最も高い) |
| | `...` / `===` / `^^^` | 続ける / リリース / すぐに止める |
| 音色 | `[a-z0-9_]{1,12}` / `..` | `..` は前の音色。新しい音の行でだけ名前を書ける |
| 音量 | `v00`〜`v15` / `...` | `...` は前の値(最初は 15) |
| 効果 | 下の表 / `...` | 最大 2 つ。次の新しい音で消える |

| 効果 | 意味(tick = 1/60 秒、効果を置いた行の始まりから数える) |
|---|---|
| `Axy` | アルペジオ: 0、+x、+y 半音を 1 tick ごと |
| `Uxx` / `Dxx` | 1 tick ごとに xx(16 進)セント上げる/下げる。`U00` で止める |
| `Gxx` | 前の音からこの行の音へ 1 tick ごとに xx セント近づける(位相とエンベロープは続ける) |
| `Vxy` | ビブラート: 速さ x × 0.5Hz、深さ y × 10 セント。`V00` で止める |
| `Wx_` | デューティ比(0: 12.5%、1: 25%、2: 50%、3: 75%) |
| `Sxx` | この行の音を xx tick 遅らせる |
| `Kxx` | xx tick 後に止める |
| `Rxx` | xx tick ごとに鳴らし直す(`R00` は不可) |

- order の `"-"` はその行数だけ休む(鳴っている音はリリース)。同じ order の行のパターンは行数をそろえる。
- `Bgm` は `loop_to` が必須。戻り先から 1 秒を続けて合成し、継ぎ目を検査する(1 秒を超える余韻が境目をまたぐとエラー E8)。
