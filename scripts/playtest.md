# 子どもの試遊(IMP-602)

小学生(低学年を含む数人。16 §4.2 Q-03)に、展示と同じ機器でゲームを遊んでもらい、分かりにくい所・長すぎる所・うるさい所などを見つけて、直す点を各担当へのカードにする手順。

- 子どもを試すのではなく、**ゲームを試す**。子どもがつまずいたら、それはゲームの直す点である。
- この手順書の「記録の表」(P0〜P8)を、子ども 1 人ごとに印刷するか写して使う。最後に「直す点の一覧」(P9)をまとめて、メインエージェントに渡す。
- 大人が先に見て直せるもの(文字の大きさ、色、機器)は `scripts/verify-hardware.md` §10 で済ませておく。音の試聴は `scripts/listen-audio.md`。

この試遊で確かめる項目:

| 項目 | 何を見るか | この手順書の場所 |
|---|---|---|
| 01 §13.4 の 1〜11 | 時間の進み方、序盤・後半、チュートリアルで止まる時間、漢字と用語、音量、BGM の飽き、乗客、路線の確認 | §5、§6、P2〜P8 |
| 13 UI-V-01 | 16px の文字とマス、24px の説明が読めるか。線路の帯で路線の数が分かるか | §5.4、P6 |
| 13 UI-V-06 | ろせんモード(作る / のばす の選択、最後の駅をもう一度押す、確認)を迷わず使えるか | §5.3、P4 |
| 13 UI-V-12 | 説明で止まる時間の合計が 200 秒以下か | §5.2、P3 |
| 15 AS-V-04 | 文字(特に画数の多い字)が展示の画面と距離で読めるか | §5.4、§6、P5・P6 |
| 15 AS-V-11 | 路線の 6 色が見分けられるか | §5.4、P6 |
| (あわせて)15 AS-V-13、13 UI-V-10、12 RT-V-04 | 線路の帯、色の見え方、路線を作ったときのカクつき | P6、P7 |

## 0. 用意するもの

| もの | 注意 |
|---|---|
| ラズパイ3B と、**`scripts/verify-hardware.md` で確かめた配布用イメージ**を書いた SD | 開発用イメージは使わない(展示と同じものにする) |
| **展示と同じ表示機器**(FullHD のテレビ・ディスプレイ。スピーカー付き) | 置き方・高さ・子どもとの距離も展示に合わせる |
| USB キーボードと、展示用のゲームパッド | 両方つないでおく |
| ストップウォッチ 2 つ(スマートフォンでよい) | 時間係が使う |
| 画面だけを撮る三脚とスマートフォン(保護者が同意したときだけ) | 子どもの顔・体・名札が写らない向きにする |
| この手順書の記録の表(子どもの人数分) | 鉛筆で書く |
| ことばのカード(§6.1) | 紙に大きく書いておく |
| 子どもの休むいす、飲み物 | |

## 1. 人の役割

大人は 3 人がよい(2 人なら、時間係と様子係を 1 人で行い、画面の動画で時間を後から測る)。

| 役割 | すること | しないこと |
|---|---|---|
| **進行役**(1 人) | 子どもと話すのはこの人だけ。始めの説明、ヒント(§4.2)、終わりの質問(§6) | 操作を教える、キー・パッドに触る |
| **時間係** | ストップウォッチでゲームを始めてからの時刻(分:秒)を測り、P2・P3 に書く | 子どもに話しかける |
| **様子係** | 子どもの様子・言ったこと(そのままの言葉)を P4〜P7 に書く | 子どもに話しかける。その場でほかの大人と話し合う |

- 観察する大人は、子どもの**斜め後ろ**に座り、画面と子どもの手元が見える位置にいる。のぞきこまない。
- 保護者には、そばで見ていてもらってよいが、**教えたり声をかけたりしないで**ほしいと先にお願いする。

## 2. 保護者の同意と、個人の情報を取らない配慮

始める前に、保護者に次を説明し、口頭で同意をもらう。同意をもらえた項目だけを行う。

> 「子ども向けの電車のゲームを作っています。分かりにくい所を見つけるために、30 分ほど遊んでもらい、その様子を記録させてください。
> - 名前は書きません。番号と学年(低学年・中学年・高学年)だけを書きます。
> - 書くのは、ゲームの時刻、どこで止まったか、言ったことばです。
> - (お願いできれば)ゲームの画面だけを動画に撮ります。お子さんの顔や声が入らないようにし、時間を測ったら消します。
> - お子さんが やめたいと言ったら、いつでも やめます。途中でやめても かまいません。」

- **書かないもの**: 名前、学校名、住所、顔写真、体の映った写真・動画。記録の表は番号だけで管理し、番号と名前の対応表も作らない。
- **学年は 3 区分**(低学年 = 1・2 年、中学年 = 3・4 年、高学年 = 5・6 年)で書く。小学生でなければ「未就学」「中学生以上」と書く。
- 画面の動画に声が入ってしまったら、時間を測り終えたら消す。動画を人に渡さない。
- 同意をもらったことは P1 の「同意」の欄に ○ を付ける(署名は取らない)。

## 3. 前の準備(子どもが来る前に)

1. 展示と同じ置き方で、表示機器・ラズパイ・キーボード・パッドをつなぐ。
2. 子どもが座る(立つ)位置から画面までの距離を測って P0 に書く。
3. 電源を入れ、タイトル画面が出ることを確かめる。
4. **表示機器の音量**を決めて P0 に書く(会場で使う音量。子どもごとに変えない)。ゲームの音量は初期値(音楽 6・音 8)のまま、せってい で変えない(01 §13.4 の 8 は初期値を確かめる項目)。
5. ゲームを一度遊んで、キーボードとパッドが効くことを確かめる。確かめたら**電源を入れ直す**(設定が初期値に戻り、チュートリアルも最初から出る)。
6. 子どもが替わるたびに、電源を入れ直す。

## 4. 試遊の進め方(1 人 30 分以内)

### 4.1 流れ

| 時間 | すること |
|---|---|
| 始める前(2〜3 分) | 進行役があいさつし、下の「始めのことば」を言う。キーボードかパッドのどちらで遊ぶか、子どもに選んでもらう(P1 に書く。人数がそろうように、迷っていたら交互にすすめる) |
| 遊ぶ(30 分まで) | 時間係が、子どもが最初に決定のボタンを押してゲームが始まった瞬間にストップウォッチを始める。様子係が記録する。進行役は見守り、決まったヒントだけを出す(§4.2) |
| 終わり | ゴール(「1無量大数円! きみは 電車王だ!」)に届くか、30 分たつか、子どもがやめたいと言ったら終わる。30 分で終わるときは「つぎで おしまいに しようね」と言って、区切りのよい所で止める |
| 終わった後(5 分) | §6 の質問をする。ありがとうを言う |

- 子どもが疲れた様子なら、途中で休んでよい(止めた時刻と再開した時刻を P2 に書く)。ゲームを止めるには Esc(パッドは Start)で せってい を開く。
- 画面が急に光る・大きな音で、子どもが怖がったり気分が悪くなったりしたら、すぐ止める(P7 に書く)。

**始めのことば**(進行役。この通りでなくてよいが、操作は教えない):

> 「これは 電車の 会社の ゲームだよ。画面に 出てくる せつめいを 見ながら、すきなように あそんでね。こまったら 『わからない』って いっていいよ。やめたく なったら いつでも いってね。」

### 4.2 ヒントの出し方

子どもが **60 秒、先に進めないでいる**(同じ画面のまま操作が止まる、同じまちがいをくり返す)か、「わからない」と言ったときだけ、次の順にヒントを出す。1 つ出したら、また 60 秒待つ。

| 段 | 進行役が言うこと・すること |
|---|---|
| 1 | 「画面の どこかに なにか 書いて あるかな?」(画面を見るように言うだけ) |
| 2 | 画面の案内の文を、そのまま読んであげる(読み上げ) |
| 3 | 押すボタンやキーを指でさす(押すのは子ども) |

- ヒントを出したら、様子係が P3(説明・案内の所なら)か P7 に、時刻・段・その前に何をしていたかを書く。**ヒントが要った所は、そのまま直す点の候補**になる。
- 段 3 でも進めないときは、進行役が「ここは こうするよ」と言ってよい(P7 に「教えた」と書く)。

### 4.3 声かけで、してはいけないこと

- 答えや操作を先に教える(§4.2 の段の外で)。
- 「はやく」「ちがうよ」「だめ」など、急かす・否定することば。
- 子どもの代わりにキーやパッドを触る。
- プレイ中に、ゲームのことば(「みりょく」など)の意味を説明する(意味は終わった後に聞く。§6)。
- 「むずかしい?」「つまらない?」のように、答えを決めてしまう聞き方。聞くときは「いま どんな かんじ?」のように開いた聞き方にする。
- 「じょうず!」を何度も言う(ほめられたくて遊び方が変わる)。「うん」「なるほど」はよい。
- ほかの子と比べる。
- 大人どうしで、子どもに聞こえる所で様子を話し合う。

## 5. 観察すること

### 5.1 時刻(時間係。P2)

ゲームが始まってからの「分:秒」を書く。

| 出来事 | 画面・音での見分け方 |
|---|---|
| 最初の路線ができた | 汽笛の音「ポッポー」(`se_line_new`) |
| 会社 Lv1、Lv2、Lv3 | 短いファンファーレ(`jingle_company_up`)と「会社レベル」の帯。新しい駅が出る |
| **会社 Lv4(全部の機能が使える)** | 少し長いファンファーレ(`jingle_all_unlocked`)と説明「これで ぜんぶ つかえるよ!」。**01 §13.4 の 1: 6.5〜9 分に来るか** |
| 会社 Lv5(BGM がにぎやかになる) | ファンファーレの後、曲が変わる |
| 会社 Lv12(BGM がもっと盛り上がる) | 同じ |
| ゴール | いちばん長いファンファーレ(`jingle_goal`)と「1無量大数円! きみは 電車王だ!」 |
| 終わり | ゴール、30 分、または子どもがやめた |

あわせて、そのときの会社レベル(画面の会社レベルの表示)も、5 分ごと(5:00、10:00、15:00、20:00、25:00、30:00)に書く(01 §13.4 の 6: シミュレーションの時刻と比べる材料)。

### 5.2 チュートリアルで止まる所(時間係・様子係。P3)

ゲームを止める説明が出ると、画面全体がうすく暗くなり、説明の箱が出る(ゲームは止まる)。子どもが読み終えて最後のページを閉じると、暗さが消えて、ゲームが動き出す。

- 時間係: 説明が出た時刻と、閉じた時刻を書く(P3)。この差が「止まった時間」。**全部の合計が 200 秒以下か**(UI-V-12、01 §13.4 の 3)。
- 様子係: 説明ごとに、読めていたか(声に出して読む、目で追う)、読まずに飛ばしたか、閉じた後に案内のとおりに操作できたか、ヒントが要ったかを書く。
- 説明の後の**案内**(画面の下などに出る「〜しよう」の文。ゲームは止まらない)で、何をすればよいか分からず止まった時間も書く(01 §13.4 の 3 には入らないが、止まる所の候補)。

説明の一覧(13 §6.3。文は短くしてある):

| # | いつ出るか | 説明(最初のページ) | 説明の後の案内 |
|---|---|---|---|
| 1 | ゲームの始め | きみは 電車の 会社の 社長だ! | なし |
| 2 | 1 の後 | えきを えらんで みよう | わくを えきに あわせてね |
| 3 | 2 の後 | えきと えきを せんろで つなごう | えきを 2つ えらんで ろせんを 作ろう |
| 4 | 最初にお金が入った | おきゃくさんが えきに つくと お金が 入るよ | なし |
| 5 | 4 の後 | ろせんを のばして 3つ目の えきに つなごう | はしの えきから 3つ目の えきへ のばそう |
| 6 | うんちんが買えるお金がたまった | うんちんを 上げよう | 「うんちん」を 上げよう |
| 7 | 2 回目の買い物 | MAXで 買えるだけ 買うよ | MAX! / おすすめ |
| 8 | ゲージが半分 | ゲージが いっぱいに なると 会社が 大きく なるよ | なし |
| 9 | 会社 Lv1 | 新しい えきが できた! | 「ろせんの 数」を 上げよう → 2本目の ろせんを 作ろう |
| 10 | 会社 Lv2 | 長い 電車は みじかい ホームには 止まれないよ | 「ホームの 長さ」→「りょうの 数」 |
| 11 | 会社 Lv3 | 電車を ふやそう / **みりょくが 高い ろせんは みんなが のりたがるよ** | 「電車の 数」→「みりょく」 |
| 12 | 会社 Lv4 | のりおりを はやく しよう | 「のりおりの はやさ」→「つめこみ」 |
| 14 | ゴール | 1無量大数円! きみは 電車王だ! | なし |
| 15 | はじめて せってい を開いた(ゲームは せってい で止まっている) | 音の 大きさを かえられるよ | なし(合計には入れない) |

### 5.3 ろせんモード(様子係。P4。UI-V-06、01 §13.4 の 11)

路線を作る・のばすたびに、次を見る:

- B(パッドは X)を押した後に出る「ろせんを 作る」「ろせんを のばす」の選択で、迷ったか。思ったのと違う方を選んだか。
- 駅を 2 つ以上選んだ後、**最後の駅をもう一度押すと完成**ということが分かったか(「もう いちど (A)で できあがり」の札を見たか)。
- 確認「あとで けせないよ。いい?」で、読んでから「はい」を選んだか、連打で決まったか。**作るつもりがなかったのに作ってしまった**か(01 §13.4 の 11)。
- 線路の曲がり方の切りかえ(Tab、パッドは右スティックの押しこみ)に気づいたか(気づかなくてもよい。使ったかを書く)。
- 「のばす」で、路線の**はしの駅**を選ぶことが分かったか(はしでない駅を選んで「ブブー」が鳴った回数)。
- 強化パネルで、左右で対象(駅・路線)を切りかえられたか(01 §13.4 の 11)。
- 路線を作った瞬間に、画面がカクッと止まったか(12 RT-V-04)。

### 5.4 見やすさ(様子係。P6。UI-V-01、AS-V-04、AS-V-11、AS-V-13、UI-V-10)

- 文字に顔を近づけたり、目を細めたりしたか(どの文字のときか)。
- 駅・列車・お客さんの数の札が見えているか(指でさして話すか)。
- 路線が 2 本以上になったら、終わった後の質問(§6)で「この せんと この せんは おなじ ろせん?」と、色の違う 2 本を指でさして聞く。同じ区間を 2 本が通っている所では「ここは なん本 とおってる?」と聞く。
- 色のことで迷った様子(「どれが どれ?」)があれば書く。

### 5.5 気持ちと音(様子係。P7。01 §13.4 の 2・4・5・8・9・10)

| 見ること | 例 |
|---|---|
| 序盤(最初の 4 分)が退屈か、速すぎるか | よそ見、手が止まる / 説明を読む前に次々と進む |
| 序盤の画面に人がまばらすぎないか | 「おきゃくさん いない」などと言う |
| 後半(会社 Lv5 から)で、何が起きているか分かっているか | 「なんで お金 ふえたの?」、画面を見ずにボタンを押し続ける |
| 飽きた場面 | あくび、立ち歩く、「まだ?」。そのときの時刻と、何をしていたか |
| 音が大きすぎる・小さすぎる | 耳をふさぐ、顔をしかめる / 音に気づかない。`se_coin`(「チャリン」)が続くときにうるさそうか |
| BGM に飽きたか(30 分近く遊んだ子) | 「この 音楽 ずっと おなじ」など |
| 怖がった場面 | 「ブブー」(`se_error`)、急なファンファーレ、「あとで けせないよ」の確認、暗くなる説明 |
| 楽しそうな場面 | 声を出して喜ぶ、「もう 1 回」 |
| 乗り換えの駅で人が急に減って、気にしたか | 「ひと きえた」など(01 §13.4 の 10) |

言ったことばは、言いかえずにそのまま書く。

## 6. 終わった後の質問(進行役。P8)

やさしく、短く聞く。答えたくなさそうなら飛ばす。

1. 「いちばん たのしかった ところは どこ?」
2. 「よく わからなかった ところは あった?」(あれば「どこ?」と画面を指してもらう)
3. 「おとの おおきさは どうだった? おおきい・ちょうどいい・ちいさい の どれ?」
4. 「おんがくは どうだった? また ききたい・ふつう・あきた の どれ?」
5. **ことばのカード**(§6.1)
6. **文字を読む**(§6.2。読める子だけ。読めなくてもよいと先に言う)
7. 路線が 2 本以上できていたら、§5.4 の色と本数の質問。

### 6.1 ことばのカード(01 §13.4 の 7)

紙に大きく次の 2 枚を書いておく。**番号が奇数の子は A から、偶数の子は B から**見せる(先に見た方を選びやすいので、順番を入れかえる)。

- A: 「みりょくが 高い ろせんは みんなが のりたがるよ」
- B: 「人気の ろせんは みんなが のりたがるよ」

1 枚ずつ見せて「これ、どういう いみだと おもう?」と聞き、答えをそのまま書く。2 枚見せた後に「どっちの ほうが わかりやすい?」と聞く。

### 6.2 文字を読む(AS-V-04、01 §13.4 の 7)

ゲームの画面に出ていた文や、数の単位を、画面かカードで読んでもらう(画面に出ていればそれを指す)。例: 「電車」「会社」「社長」「お金」「万」「億」「兆」。読めた字・読めなかった字を書く。

- 画数の多い字(曜、議、穣、澗)を、画面と同じ大きさで見せたいときは、開発機を同じ表示機器につなぎ、`scripts/verify-hardware.md` §10 の 3. で作った `font16.png` を全画面で出す(ラズパイの代わりにつなぐので、試遊の合間に行う)。読み方は聞かなくてよい。「字の 形が はっきり 見える?」と聞く。

## 7. 終わった後のまとめ(大人だけで)

1. 子どもが帰ってから、3 人で記録を見合わせ、抜けを足す。画面の動画があれば、P2・P3 の時刻を動画で確かめ、測り終えたら動画を消す。
2. 全員の分がそろったら、P9 の「直す点の一覧」を書く(§8)。
3. 時刻の記録(P2)は、そのままメインエージェントにも渡す(01 §13.4 の 1・6 を、シミュレーションの時刻と比べるのに使う。IMP-601)。

## 8. 直す点の一覧の書き方(カード)

見つけた問題を、**1 つの問題につき 1 枚のカード**にする。カードはメインエージェントが各担当(01、11、13、14、15 など)への作業のカードに切り出す。直す作業は、この試遊の中ではしない。

**書き方の決まり**

- 「見たこと(事実)」と「直す案(意見)」を分けて書く。
- 何人中何人に起きたかを書く(1 人だけのことも書く。重さで分ける)。
- 子どもは番号で書く(名前を書かない)。
- 直す案はあってもなくてもよい。決めるのは担当。

**重さ**

| 重さ | 意味 |
|---|---|
| A | 先に進めなくなった、ヒントの段 3 か教える必要があった、怖がって止めた。リリースの前に直す |
| B | 迷ったが自分で進めた、ヒントの段 1・2 で進めた、2 人以上が気にした |
